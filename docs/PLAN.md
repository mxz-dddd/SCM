## 1. 项目概述

## 2. 技术方案基线（对 Codex 冻结，不再讨论）

| 层 | 选型 |
|---|---|
| Monorepo | pnpm workspaces + Turborepo：`apps/web`、`apps/api`、`apps/worker`、`packages/shared`（类型/事件契约/枚举）、`packages/ui`（组件库） |
| 前端 | React 18 + TypeScript + Vite + Ant Design 5 + TanStack Query + Zustand；ECharts（看板）、高德/Leaflet（地图）、FullCalendar（预约日历） |
| 后端 | NestJS 10 模块化单体，按 bounded context 分模块：platform / mdm / oms / wms / tms / ams / billing / control / integration |
| 数据 | PostgreSQL 16（Prisma，multiSchema：每域独立 schema）；Redis 7（缓存/短锁/BullMQ）；MinIO（附件，S3 协议）；MeiliSearch 或 PG 全文（统一搜索） |
| 事件 | 事务 Outbox 表 + 投递 worker + 消费者 Inbox 去重（首期进程内/BullMQ，达到阈值再换 Kafka/RabbitMQ，契约不变） |
| 认证 | JWT + 租户上下文中间件；RBAC 资源权限 + ABAC 数据范围；OIDC 预留 |
| 测试 | Vitest（单测/状态机模型测试）+ Supertest（API）+ Playwright（E2E）+ 专项并发测试（库存/时隙） |
| CI/CD | GitHub Actions：lint + typecheck + test + build；`pnpm verify` 为统一门禁；docker-compose 本地一键起环境 |

**硬性架构规则**（Codex 违反即返工）：所有业务表带 `tenant_id/version/created_*/updated_*`；金额用 Money(amount+currency)，禁浮点；状态只经领域命令变更；跨域禁 JOIN、禁外键，只存对方 ID+快照；跨域写走命令/事件（Outbox/Inbox + 幂等键）；规则决策保存命中/排除/版本追踪。

## 6. 质量与验收

- **门禁**：每个 WP 完成必须 `pnpm verify`（lint+typecheck+单测）绿；状态机变更必须有模型测试；库存/时隙必须有并发测试。
- **六大最小验收场景**（§13.2）：①订单全链路 ②ASN→预约→收货 ③库存并发不超卖/RF 重放不重复扣减 ④时隙并发唯一/改期失败保持原预约 ⑤拒单释放容量/POD 退回不可结算 ⑥费率变更不改历史、重算新版本可解释。
- **每日对账任务**：订单-履约、库存-流水、运单-POD、计费-凭证（§11.4）。
- **权限矩阵测试**：越权请求必须由后端拒绝，作为发布门禁。

## 7. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 五类一致性（订单承诺/库存并发/运输事件/时隙容量/费率追溯）实现错误 | 高 | 不变量写入 AGENTS.md 硬规则；每个聚合先写状态机模型测试再写实现；专项并发测试进 CI |
| Codex 长任务上下文漂移、擅自改架构 | 高 | 任务卡粒度 ≤3 天；AGENTS.md 冻结技术栈与规则；每 WP 独立提交，人工 review 关键聚合（库存/时隙/计费） |
| 现网核验受限，字段/交互与真实系统偏差 | 中 | P0 差异台账持续更新；按证据等级 A/B/C 决定照做或自定义；只用合法只读方式采集 |
| 范围蔓延（241 项 + 行业扩展） | 中 | 变更只进 BACKLOG 新增 WP，不插队当前阶段；每阶段冻结范围 |

## 8. Codex 目标模式执行说明

三个仓库文件驱动 Codex 自主执行（详见《CODEX_目标模式命令.md》）：

1. `AGENTS.md`（仓库根）—— Codex 自动读取的守则：技术栈冻结、硬性规则、DoD、工作流程。
2. `docs/PLAN.md` —— 本计划书。
3. `docs/BACKLOG.md` —— 58 张任务卡（勾选制），Codex 每次运行取第一张未完成卡，实现→测试→`pnpm verify`→勾选→commit，循环直至阶段完成或遇阻塞（写入 `docs/QUESTIONS.md` 并停止）。

人工保留职责：P0 现网核验、每阶段验收、关键聚合 code review、QUESTIONS.md 决策、生产部署。
