# V2-07 验收记录

- 新增 `react-router-dom@7.18.1`，以 `route-registry.tsx` 统一生成 37 个管理端路由、导航、账号类型权限、懒加载、错误边界和 Workspace Tab 元数据。
- `ApplicationShell` 改为 layout + `Outlet`；pathname 与标签双向同步，支持地址栏直达、刷新、浏览器历史、复制深链、旧 `/mobile/portal` 重定向和稳定 403。

- 新增全注册路由匹配/懒加载、深链、历史与标签同步、账号类型拒绝、旧链接、四终端移动视口和 token 导出测试；既有 31 个页面测试保持通过。
- 已创建差异台账模板与原创 token 基线；P0-01、P0-02 仍保持未勾选，等待人类证据和批准。
