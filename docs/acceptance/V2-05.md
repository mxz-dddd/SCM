# V2-05 验收记录

- API 启动启用 Helmet、显式 CORS allowlist、JSON/urlencoded body 上限、可配置可信代理和 shutdown hooks；错误模型不返回 stack 并保留 correlation id。
- 真实 `/api/v1/external/**` 使用 Request 派生 method/path/IP/raw body bytes/hash 的全局 Gateway Guard；管理员 simulation 受 RBAC 保护并标记弃用。
- 登录、普通 API 与外部凭据分别使用 PostgreSQL 原子计数；HMAC 签名持久化单次使用，现有 minute/day/sensitive quota 继续写不可变决策和日志。
- Webhook 创建与投递前双重验证 endpoint；Worker 固定到已验证公共 IP、校验证书 hostname、不跟随 redirect，限制连接/总超时与响应体。
- 覆盖 401/403/413/429、HMAC 重放、伪造 route/method、并发配额、私网/metadata/IPv6/DNS 私网、302 私网和响应上限相关测试。
