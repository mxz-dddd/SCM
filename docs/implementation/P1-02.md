# P1-02 数据基线实现说明

## 规格映射

- Prisma datasource 声明九个领域 Schema；首个迁移从空 PostgreSQL 16 实例创建这些 Schema。
- `platform.data_baseline` 是数据规则的可执行参考模型，覆盖租户字段、审计字段、乐观锁版本、状态、Money、双单位数量、PackageSpec 版本和受控扩展字段。
- 所有索引以 `tenant_id` 开头；本卡不创建跨领域关系或数据库外键。
- Money 与数量在共享契约中使用十进制字符串，禁止经 JavaScript `number` 产生精度损失。

## API 与测试适用性

本卡是持久化基础设施卡，不提供业务写 API 或状态命令。因此认证/权限拒绝、业务状态转换、`Idempotency-Key` 重放和 Outbox/Inbox 测试不适用；这些要求由首次引入对应命令的任务卡落实。当前测试覆盖值对象正常/拒绝路径、Schema 必填字段、九域迁移、tenant-first 索引、Decimal/受控 JSON 约定及禁止跨域外键。
