# P1-03 租户与认证实现说明

## 规格映射

- PLT-001：租户按 `PROVISIONING → ACTIVE → SUSPENDED → ACTIVE/ARCHIVED` 状态机流转；命令使用 `expectedVersion` 乐观锁，并在同一事务写入审计与 Outbox。
- PLT-003：人员、账号、组织和身份绑定分表；账号保留启停、锁定、有效期、失败次数及权限版本字段，身份绑定承载组织归属。
- PLT-004：实现本地密码登录、HS256 JWT、租户上下文校验、服务账号与 API 凭证；密码使用带随机盐的 scrypt，API 密钥仅保存 SHA-256 摘要和末四位。
- 所有平台实体包含租户、审计、版本和状态字段；索引均以 `tenant_id` 开头，不建立跨域数据库外键。

## API 与事件

- `POST /api/v1/auth/login`：校验租户、账号、密码、锁定和有效期，签发带租户、组织、设备和权限版本的 JWT，并记录成功或失败审计。
- `POST /api/v1/platform/tenants`：平台管理员创建租户、根组织和初始管理员；需要 `Idempotency-Key`。
- `POST /api/v1/platform/tenants/:tenantId/transitions`：平台管理员按期望版本推进租户状态；需要 `Idempotency-Key`。
- `POST /api/v1/platform/service-accounts`：平台或租户管理员创建服务账号和一次性展示的 API 密钥；需要 `Idempotency-Key`。
- 写命令产生 `platform.tenant-provisioned.v1`、`platform.tenant-status-changed.v1` 或 `platform.api-credential-created.v1` Outbox 事件；请求与审计统一携带 `X-Correlation-Id`。

## 验证记录

- 单元测试覆盖状态机正常与非法转换、账号类型权限拒绝、密码验真、JWT 篡改、凭证派生和幂等同载荷重放/异载荷冲突。
- Web 测试覆盖登录入口和租户生命周期工作台渲染。
- PostgreSQL 16 冒烟覆盖登录、租户创建、语义一致的幂等重放、载荷冲突、激活、租户登录、权限拒绝、非法转换、服务账号重放及密钥明文不落库。
- 独立空库依次应用两份迁移；种子连续执行两次后仍为一个平台租户、一个平台账号和一个身份绑定。
