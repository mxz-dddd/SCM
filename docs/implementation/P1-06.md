# P1-06 应用壳与多标签会话实现说明

## 规格映射

- PLT-007：实现原创深色窄侧栏、浅色上下文顶栏和多标签内容区；顶部支持租户、组织、仓库、语言与用户上下文，侧栏覆盖工作台、平台、订单、仓储和运输模块入口。
- 标签保存路由、查询条件、草稿和 dirty 状态；干净标签直接关闭，脏标签必须确认。关闭当前标签后按稳定邻位选择下一标签。
- `WorkspaceLayout`、`PageSession` 与 `Favorite` 均按可信 tenant+account 隔离；登录后先恢复服务端布局、最近访问和收藏，再启用防抖保存，避免初始状态覆盖已保存布局。
- 全局命令面板支持按钮及 `⌘/Ctrl+K` 键盘入口，并与侧栏复用同一页面注册表。

## API

- `GET /api/v1/platform/workspace`：返回当前账号布局、最近二十次页面会话和收藏。
- `PUT /api/v1/platform/workspace`：保存上下文、活动标签和开放标签；需要 `Idempotency-Key`。
- `PUT /api/v1/platform/workspace/page-sessions`：保存页面查询条件、草稿、dirty 状态和访问时间；需要 `Idempotency-Key`。
- `POST /api/v1/platform/workspace/favorites/toggle`：幂等切换当前账号收藏。
- 所有权条件均从 JWT 租户上下文派生，不接受请求体账号 ID；布局保存写入审计。

## 验证记录

- 单元测试覆盖干净关闭、脏关闭拒绝/确认、关闭后的活动标签选择和可信 tenant/account 所有权条件。
- Web 测试覆盖模块导航、四类上下文选择器、工作台标签和全局命令面板。
- PostgreSQL 冒烟覆盖布局/页面会话/收藏正常路径、语义一致幂等重放、异载荷冲突 409、非法租户上下文 400、dirty/query 恢复及同租户双账号隔离。
- 独立空库依次应用五份迁移并连续运行两次种子，三张个人工作区表及 JSON 形状约束均创建成功。
