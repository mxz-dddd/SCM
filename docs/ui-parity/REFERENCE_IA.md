# 参考站信息架构（只读观察）

> 本文只记录用户可见的信息架构和抽象布局，不包含参考站截图、HTML、CSS、源码、品牌素材或业务数据。原始证据位于 Git 忽略目录 `.artifacts/ui-reference/`。

## 全局层级

参考站采用三层导航模型：

1. 左侧深色窄栏只放产品/业务大类；
2. 选择大类后，在页面顶部横向显示该产品的业务组；
3. 业务组展开后显示叶子页面；页面级查询、工具栏和状态动作留在内容区。

已观察到 8 个一级大类，顺序为：

1. 仓储管理
2. 订单管理
3. 运输管理
4. 基础资料
5. 报表
6. 消息管理
7. 系统支持
8. 数据大屏

此外存在独立 AI 能力入口，但其内容属于能力商店/助手，不作为 SCM 核心业务叶子菜单映射。

## 仓储管理

- 入库管理：入库订单、入库码盘、收货、质检、上架、质检明细、入库明细、码盘明细、质检结果、收货明细。
- 库存管理：库存查询、库存快照、交易查询、库存调整、库存移动、库存冻结、库存转移、库存盘点、货权转移；另有补货、箱托、标签、序列号、库存养护和库存监控等下级分组。
- 出库管理：出库订单、出库执行；另有波次、装箱、装车、封条、交接、发货确认、转仓单及各类执行明细。
- 任务管理：作业看板、规则设置、上架/备货/拣货/补货任务、波次任务、抽检和绩效。
- WES 管理：设备与调度规则、打印、复核、称重、分拣、理货及智能设备任务。
- 增值服务：生产班组、生产线、生产计划、组装/拆装/库内/异常工作单及生产统计。
- 计费管理：合同与费率、服务/计价/结算/费用类型、应收、应付。
- 分析优化：ABC 动态分析。
- 基础资料：贸易伙伴、货品、货位、资产、容器、设备、格口等。
- 设置：系统代码、系统设置、属性、操作跟踪、数据隔离、业务单号、接口及各类业务规则。

## 订单管理

- 订单中心：采购、销售、平台、交易、售后、增值、营销、渠道等订单及明细。
- 订单执行：入库订单、出库订单、差异调整、退货申请和执行明细。
- 库存中心：全局库存、逻辑仓库存与快照、移仓/转移/货权/冻结及异常交易。
- 基础资料：规则体系、渠道管理、物理仓/渠道仓/逻辑仓、库存映射、渠道/店铺和平台货品映射。
- 设置中心：自定义、系统设置、业务单号、数据隔离、用户权限、工作日历、业务日志和标签。

## 运输管理

- 仪表盘。
- 订单：订单、发货订单、满意度调查汇总、运费查询。
- 计划：货源竞价、配载、波次模板/计划、配载路线、调度池、片区配载、运力需求、货源报价。
- 执行：运单、预约、发货控制台、车辆进出厂、排队、委托/订舱、在途/到站/清关、回单、异常/投诉/货差/冷链、轨迹和控制塔。
- 结算：合同与费率、询报价、应收、应付、现金、预支、报销、毛利和收入。
- 设置：常规设置、数据隔离、路线、业务规则、业务单号、数据服务、电子围栏/签单和 BI 管理。

## 基础资料

- 贸易伙伴：货主、客户、供应商、承运商。
- 货品管理：货品、包装、批次、计量单位、产品类型、套装、属性和容器/货权映射。
- 地域管理：地址、地址矩阵、月台、国家/省市区县/街道和片区。
- 运力管理：运输方式、司机、设备、挂车、集装箱、GPS、船期和航班。
- 车队管理：维修、年检、证件、保险、保养、违章、费用、出勤和加油。
- 费用设置：费用类型、预算、开票、仓储/运输费率和应付、汇率、税率。
- 组织管理：销售组织、工厂、项目、区域、产品线、库存地点、成本中心、业务组织/部门和会计科目。
- 附件中心：附件查询及新版查询。
- 综合管理：设备、外部平台账号、作业标准工时、安全考核和账期回传控制。
- 设置：低代码/数据字典/个性化、计价结算、费率基础、全局/页面/模板自定义、数据隔离及日历时间窗。

## 报表与消息

- 报表：BI 报表、我的报表、自定义报表、自定义打印、按 OMS/WMS 主题分组的报表设置。
- 消息：事件列表、事件订阅、公告管理、发送记录、设置中心。

## 系统支持与数据大屏

- 系统支持：全局关键词搜索、直接提问、Open API 文档，以及在线帮助、PDV 操作手册、用户手册、视频教程、常见问题、更新说明等内容入口。它属于帮助中心，不应复制进业务导航；本地只需提供原创帮助/文档入口和运维联络方式。
- 数据大屏：大屏管理、大屏分组、我的大屏、地图管理；列表包含分组、发布状态、分页和模板/实例卡片。新建、导入、导出属于写操作，本次没有触发。
- 报表“我的报表”中可见 TMS、WMS、库存、结算、时效、异常和控制塔等主题目录，说明统一报表目录与业务模块报表入口需要同时存在。

## 页面层级边界

- 一级大类：产品/业务域切换，只在左侧窄栏出现。
- 二级业务组：当前大类顶部横向菜单。
- 三级页面：二级菜单展开后的叶子项；点击后进入内容工作区或创建内部页签。
- 页面操作：查询、创建、审核、执行、打印、导出等不属于一级导航；本次只观察，未触发写操作。
- 详情/弹窗：属于页面内部交互，不提升为左侧菜单。
